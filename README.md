# 🎬 LinkStream

## ▶️ How to Use

1. Open the website  
   https://manishkumarsingh41.github.io/LinkStream/

2. Paste any URL into the input box

3. The app will automatically generate a modified "play" link

4. Choose any option:
   - ▶ Play → Watch inside the same page  
   - 🔗 Open Link → Open in a new tab  
   - 📋 Copy Link → Copy the modified URL  

5. (Optional)  
   - Use fullscreen while playing video  
   - Use available video controls (depends on source)
